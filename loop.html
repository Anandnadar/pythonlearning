Python Loops - Quick Reference

1. Types of Loops

Loop Type Description When to Use
For Loop Iterates over a sequence or range. When iterating over a known sequence.
While Loop Executes while a condition is True. When the number of iterations is unknown.
Nested Loop A loop inside another loop. Patterns, matrices and multiple iterations.
List Comprehension Short syntax for creating lists using iteration. When creating a new list.

2. For Loop

Used to iterate over a sequence or a known range.

for i in range(5):
    print(i)

Output:

0
1
2
3
4

3. While Loop

Used to execute a loop as long as a condition is True.

i = 0

while i < 5:
    print(i)
    i += 1

Output:

0
1
2
3
4

4. Nested Loop

A loop inside another loop.

for i in range(3):
    for j in range(2):
        print(i, j)

Output:

0 0
0 1
1 0
1 1
2 0
2 1

5. List Comprehension

A shorter way to create a list using iteration.

numbers = [1, 2, 3, 4, 5]

squares = [number * number for number in numbers]

print(squares)

Output:

[1, 4, 9, 16, 25]

6. Loop Control Statements

Statement Description
break Stops the loop immediately.
continue Skips the current iteration.
pass Does nothing; acts as a placeholder.

7. Range Function

Syntax Output
range(5) 0, 1, 2, 3, 4
range(1, 5) 1, 2, 3, 4
range(1, 10, 2) 1, 3, 5, 7, 9

8. Important Notes

  • Always update the condition variable in a while loop.
  • Python uses indentation to define the loop body.
  • Use break to stop a loop.
  • Use continue to skip an iteration.
  • Use list comprehension for concise list creation.

End of Python Loops Notes
